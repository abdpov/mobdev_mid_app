# Task Manager (mobdev_mid_app)

Кроссплатформенное мобильное приложение на **Flutter**, разработанное в рамках мидтерма по мобильной разработке.

## 📱 Выполненные критерии
1. **Cross-platform**: приложение разработано на **Flutter** и поддерживает запуск на Android, iOS, Web и Desktop.
2. **Взаимодействие с сервером**: клиент общается с REST API (`https://dummyjson.com/todos`) через HTTP-запросы (GET, POST, PUT, DELETE):
   - Загрузка списка задач с удаленного сервера (`GET /todos`)
   - Создание новой задачи (`POST /todos/add`)
   - Обновление статуса выполнения (`PUT /todos/{id}`)
   - Удаление задачи (`DELETE /todos/{id}`)
3. **State Management**: архитектура построена на **BLoC** (`flutter_bloc`):
   - Разделение на события (`TodoEvent`), состояния (`TodoState`) и бизнес-логику (`TodoBloc`).
   - Поддерживаются состояния загрузки, успешного получения данных и обработки ошибок сети.
4. **GitHub**: проект версионируется и опубликован в GitHub-репозитории.

## 🏗 Архитектура проекта

Структура исходного кода (`lib/`):
```text
lib/
├── bloc/
│   ├── todo_bloc.dart    # Бизнес-логика обработки событий и мутации состояний
│   ├── todo_event.dart   # События: Load, Add, Toggle, Delete, Filter
│   └── todo_state.dart   # Состояния: Initial, Loading, Loaded, Error
├── models/
│   └── todo.dart         # Модель данных Todo с сериализацией JSON
├── screens/
│   ├── home_screen.dart  # Главный экран со списком задач, фильтрами и прогресс-баром
│   └── widgets/
│       ├── add_todo_sheet.dart  # Модальное окно добавления новой задачи
│       └── todo_item_tile.dart  # Карточка отдельной задачи с чекбоксом и удалением
├── services/
│   └── todo_service.dart # Сетевой сервис для работы с REST API через http
└── main.dart             # Точка входа в приложение, DI для BLoC и тема Material 3
```

## 🚀 Основной функционал
- **Загрузка и Pull-to-Refresh**: обновление актуального списка с сервера свайпом вниз.
- **Фильтрация**: переключение между вкладками «Все», «Активные» и «Завершенные».
- **Индикатор прогресса**: наглядная шкала выполнения текущих задач.
- **Добавление задачи**: быстрый ввод через модальное окно.
- **Переключение статуса**: мгновенное обновление UI и отправка запроса на сервер.
- **Удаление**: удаление задачи с уведомлением SnackBar.

## 🛠 Запуск проекта

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/abdpov/mobdev_mid_app.git
   cd mobdev_mid_app
   ```
2. Установить зависимости:
   ```bash
   flutter pub get
   ```
3. Запустить проект:
   ```bash
   flutter run
   ```
